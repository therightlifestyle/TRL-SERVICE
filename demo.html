What this demo is—and isn’t

A transparent example, not a result.

This tool uses a small set of fixed rules in your browser to create a generic sequence: capture, assign, set a next action and review. It does not use generative AI, make a clinic-specific recommendation, connect to a database or guarantee business outcomes.
